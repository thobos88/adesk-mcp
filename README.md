# adesk-mcp — MCP-сервер для Adesk (только чтение)

Свой MCP-сервер для сервиса финансового учёта [Adesk](https://adesk.ru).
Вы спрашиваете Claude по-русски: «какая прибыль за август?», «сколько потратили на материалы в сентябре?»,
«что по деньгам у объекта по договору 123?». Claude сам вызывает нужный инструмент и отвечает по данным Adesk.

- **Только чтение.** К Adesk уходят только GET-запросы к четырём адресам. Любой другой метод
  отклоняется в коде до сетевого запроса; это проверяет тест.
- **Без сторонних пакетов.** Один файл `server.py`, только стандартная библиотека Python 3.10+.
- **Ключ — только в переменных окружения.** В коде, ответах и журнале ключа нет.
- **Обработка — снаружи Adesk.** Сервер берёт сырые операции и сам считает итоги.

## Инструменты

| Инструмент | Что делает |
|---|---|
| `adesk_accounts` | Счета и остатки на сейчас, итоги по юрлицам |
| `adesk_projects` | Поиск проектов (объектов, договоров) по части названия или категории |
| `adesk_project_money` | Доходы и расходы по одному объекту: итоги, по статьям, список операций |
| `adesk_pnl_month` | ОПиУ за месяц по дате начисления: выручка, расходы по статьям, прибыль |
| `adesk_totals_by_category` | Расходы или доходы по статьям за период |
| `adesk_operations` | Операции за период с фильтрами: статья, проект, контрагент, текст, сумма |
| `adesk_categories` | Справочник статей: доход или расход, вид деятельности |

Все суммы — в рублях. Период — до 366 дней. Каждый вызов читает свежие данные, кэша нет.

## Как считается ОПиУ (прибыль)

1. Операции берутся **по дате начисления**, а не по дате платежа. Для разбитой операции у каждой части своя дата и статья.
2. В расчёт идут только статьи **операционной деятельности**.
3. Не входят: переводы между счетами, плановые операции, инвестиционные и финансовые статьи
   (кредиты, дивиденды, займы), операции без статьи. Инструмент показывает их отдельной строкой.
4. Месяц **окончателен с 11-го числа следующего месяца**. До этого зарплату и другие расходы ещё начисляют
   задним числом, и ответ помечается «месяц ещё не окончателен». Закрытые месяцы тоже могут исправляться задним числом.

## Подключение к Claude Code

Нужен ключ API Adesk (выдаётся в настройках Adesk). Ниже — два варианта.

### Вариант 1. Сервер на своей машине

1. Положите ключ в файл с правами только для себя:

   ```bash
   printf 'ADESK_API_TOKEN=ваш_ключ\n' > ~/.adesk.env && chmod 600 ~/.adesk.env
   ```

2. Подключите сервер:

   ```bash
   claude mcp add adesk -e ADESK_ENV_FILE="$HOME/.adesk.env" -- python3 /путь/к/server.py
   ```

Можно передать ключ сразу переменной `-e ADESK_API_TOKEN=...`, но тогда он попадёт в конфиг Claude Code открытым текстом.
Файл с правами 600 надёжнее.

### Вариант 2. Ключ остаётся на вашем сервере

Сервер запускается по ssh только на время сессии Claude Code и завершается вместе с ней.
Ключ лежит на сервере и на ваш компьютер не попадает. Демонов, cron и открытых портов нет.

1. Скопируйте `server.py` на сервер, например в `/opt/adesk-mcp/`.
2. На сервере положите ключ в `.env` с правами 600.
3. Подключите:

   ```bash
   claude mcp add adesk -- ssh -o BatchMode=yes ваш-сервер 'ADESK_ENV_FILE=/путь/к/.env python3 /opt/adesk-mcp/server.py'
   ```

`BatchMode=yes` нужен, чтобы ssh не ждал ввода пароля, а сразу сообщил об ошибке.
Флаг `-s user` делает сервер доступным во всех папках, без него — только в текущем проекте.

Проверка: `claude mcp list` → у `adesk` статус «Connected». Затем спросите Claude: «Какая прибыль за прошлый месяц по Adesk?».

## Безопасность

- Методы, кроме GET, и адреса вне списка `bank-accounts`, `projects`, `transactions`, `transactions/categories`
  отклоняются до сети (`ReadOnlyViolation`). У клиента одна публичная операция — `get()`.
- Ключ читается из `ADESK_API_TOKEN` или из файла `ADESK_ENV_FILE`. В сообщениях об ошибках адрес запроса скрыт,
  а ключ заменяется на `***`.
- `.env` занесён в `.gitignore`. Не коммитьте ключ.
- Ответы инструментов содержат ваши финансовые данные, и они уходят модели, с которой вы работаете. Учитывайте это.
- После изменений кода прогоняйте тесты и проверяйте diff на секреты.

## Тесты

```bash
python3 -m unittest -v test_server.py
```

Тесты работают без сети на выдуманных данных: протокол MCP, запрет не-GET, отсутствие ключа в ошибках,
расчёт ОПиУ (переводы, финансовые статьи, разбитые операции, дата начисления), дочитывание оборванной выдачи.

## Технические детали

- Транспорт stdio, JSON-RPC 2.0, одно сообщение на строку. Журнал — только в stderr.
- Версии протокола: 2025-11-25, 2025-06-18, 2025-03-26, 2024-11-05. На `server/discover` (спецификация 2026-07-28)
  сервер отвечает «метод не найден», и клиент по правилам спецификации переходит на `initialize`.
- Выдача операций Adesk постранично иногда обрывается. Сервер читает окнами по 4 дня, сверяет число строк
  с `recordsFiltered`, при обрыве делит окно пополам, а внутри одного дня дочитывает страницами.
- По дате начисления операции выбираются фильтром Adesk `date_type=accrual`.
- При завершении сервер пишет в stderr пик памяти процесса.
